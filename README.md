# Project_Shopping_Store:

I checked your project files. Your project is a **Shopping Store (E-Commerce Website)**.

 ✅ What this project is

It is a fully functional online shopping website where users can:

* Browse products
* Add items to cart
* View shopping cart
* Proceed to checkout
* (Based on README: includes authentication, filtering, and payment concept)


🛠️ Tools / Technologies used

Your project is made using these tools:

 1.HTML (HyperText Markup Language):

* Used to create the structure of the website
* Example: homepage, product sections, cart page

 2. CSS (Cascading Style Sheets):

* Used for designing and styling the website
* Controls colors, layout, fonts, and responsiveness

 3. JavaScript:

* Used to add functionality and interactivity
* Example:

  * Add to cart system
  * Product handling
  * Button actions
  * Dynamic updates on page

* Used for icons (like cart icon, search icon, etc.)
